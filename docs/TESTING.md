# План тестування

## 1. Головне меню

| Ввід | Очікуваний результат |
|---|---|
| `1` | Відкривається завдання 1 |
| `2` | Відкривається завдання 2 |
| `3` | Відкривається завдання 3 |
| `4` | Відкривається завдання 4 |
| `0` | Програма коректно завершується |
| `9` | Повідомлення про помилку, повторний вибір |
| `abc` | Повідомлення про помилку, повторний вибір |
| порожній рядок | Повідомлення про помилку, повторний вибір |

## 2. Перевірка року на високосність

| Рік | Очікування | Причина |
|---:|---|---|
| 2024 | високосний | кратний 4, не кратний 100 |
| 2025 | не високосний | не кратний 4 |
| 1900 | не високосний | кратний 100, але не 400 |
| 2000 | високосний | кратний 400 |
| 2100 | не високосний | кратний 100, але не 400 |

Некоректне введення:
- `abc` → повторний запит;
- `0` → повторний запит;
- `-2024` → повторний запит.

## 3. Трикутник

### Висота 1
```text
1
```

### Висота 4
```text
   1
  2 2
 3 3 3
4 4 4 4
```

Перевірити:
- `0` → повторний запит;
- `-1` → повторний запит;
- `abc` → повторний запит;
- `10` → 10 рядків, двоцифрове число не руйнує читабельність форми.

Ключові перевірки: кількість рядків повинна точно дорівнювати введеній висоті, а кожен рядок має бути відцентрований відносно основи, щоб трикутник мав дві похилі сторони.

## 4. Мільйонер

### Підменю
- `1` → демо-версія на 5 питань;
- `2` → повна гра на 15 питань;
- `0` → повернення до головного меню;
- неправильне значення → повторний запит.

### Демо-версія

Перевірити:
1. усі 5 відповідей неправильні → гра доходить до питання 5, підсумок 0 балів;
2. дві правильні та три неправильні → підсумок 200 балів;
3. усі 5 правильні → 500 балів;
4. неправильна відповідь → показ правильної відповіді та перехід до наступного питання;
5. `7` або `abc` → повторний запит без зміни рахунку;
6. після п’ятого питання → підсумок і повернення до головного меню.

### Повна гра

Перевірити:
1. рівно 15 питань;
2. після неправильних відповідей користувач усе одно доходить до `Питання 15 з 15`;
3. усі 15 правильних відповідей → `1500 із 1500 балів`;
4. кожне питання має 4 варіанти та одну правильну відповідь;
5. після п’ятнадцятого питання → підсумок і повернення до головного меню.

Джерела повної гри перевіряються окремо за [FULL-GAME-SOURCES.md](FULL-GAME-SOURCES.md).

## 5. Калькулятор

| Вираз | Очікування |
|---|---:|
| `5 + 5 * 10 + 4 / 2 - 3` | 54 |
| `2 + 3 * 4` | 14 |
| `20 / 5 + 3` | 7 |
| `10 - 2 * 3` | 4 |
| `8 / 2 * 2` | 8 |
| `20 - 5 - 3` | 12 |
| `1 + 2 + 3` | 6 |
| `5+5*10+4/2-3` | 54 |
| `10,5 + 0,5` | 11 |
| `10 / 4` | 2.5 |

Тести `8 / 2 * 2 = 8` і `20 - 5 - 3 = 12` перевіряють виконання операцій однакового пріоритету зліва направо.

Окремо перевіряємо, що калькулятор працює як із пробілами, так і без них, а також коректно приймає десятковий роздільник `,` або `.`.

Помилкові сценарії:
- `5 / 0` → повідомлення про ділення на нуль;
- порожній рядок → помилка;
- `5 +` → помилка про відсутній операнд;
- `5 ** 2` → помилка про некоректну послідовність;
- `hello` → повідомлення про невідомий символ;
- `2 3` → повідомлення про пропущений оператор;
- дуже велике число, що не вміщується в `decimal` → контрольована помилка без аварійного завершення програми.

## 6. Перевірка переходів між модулями

1. Відкрити завдання 1 → виконати → повернутися до меню.
2. Відкрити завдання 2 → виконати → повернутися до меню.
3. Відкрити гру → дати неправильну відповідь → переконатися, що гра продовжується → завершити режим → повернутися до меню.
4. Відкрити калькулятор → обчислити приклад → повернутися до меню.
5. Обрати 0 → програма завершується.

Цей блок перевіряє саме наше додаткове меню, а не окремі алгоритми викладача.
