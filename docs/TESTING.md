# План тестування

## 1. Головне меню

| Ввід | Очікуваний результат |
|---|---|
| `1` | Відкривається завдання 1 |
| `2` | Відкривається завдання 2 |
| `3` | Відкривається завдання 3 |
| `4` | Відкривається завдання 4 |
| `0` | Програма коректно завершується |
| `9` | Повідомлення про помилку, повторний вибір |
| `abc` | Повідомлення про помилку, повторний вибір |
| порожній рядок | Повідомлення про помилку, повторний вибір |

## 2. Перевірка року на високосність

| Рік | Очікування | Причина |
|---:|---|---|
| 2024 | високосний | кратний 4, не кратний 100 |
| 2025 | не високосний | не кратний 4 |
| 1900 | не високосний | кратний 100, але не 400 |
| 2000 | високосний | кратний 400 |
| 2100 | не високосний | кратний 100, але не 400 |

Некоректне введення:
- `abc` → повторний запит;
- `0` → повторний запит;
- `-2024` → повторний запит.

## 3. Трикутник

### Висота 1
```text
1
```

### Висота 4
```text
      1
    2 2
  3 3 3
4 4 4 4
```

Перевірити:
- `0` → повторний запит;
- `-1` → повторний запит;
- `abc` → повторний запит;
- `10` → 10 рядків, двоцифрове число не руйнує читабельність форми.

Ключова перевірка: кількість рядків повинна точно дорівнювати введеній висоті.

## 4. Мільйонер

Перевірити наявність рівно 5 питань, серед яких:
- питання про кольори прапора України;
- питання про місто, у якому знаходиться ДТЕУ;
- три додаткові питання.

Сценарії:
1. Перша відповідь неправильна → 0 балів і завершення поточної гри.
2. Дві правильні, третя неправильна → 200 балів.
3. Усі 5 правильні → 500 балів.
4. `7` на питанні → повторний запит, рахунок не змінюється.
5. `abc` → повторний запит, рахунок не змінюється.
6. Після завершення гри → повернення до головного меню.

Окремо перевірити:
- рівно 4 варіанти у кожного питання;
- лише одну правильну відповідь у кожного питання.

## 5. Калькулятор

| Вираз | Очікування |
|---|---:|
| `5 + 5 * 10 + 4 / 2 - 3` | 54 |
| `2 + 3 * 4` | 14 |
| `20 / 5 + 3` | 7 |
| `10 - 2 * 3` | 4 |
| `8 / 2 * 2` | 8 |
| `20 - 5 - 3` | 12 |
| `1 + 2 + 3` | 6 |
| `5+5*10+4/2-3` | 54 |
| `10,5 + 0,5` | 11 |
| `10 / 4` | 2.5 |

Тести `8 / 2 * 2 = 8` і `20 - 5 - 3 = 12` перевіряють виконання операцій однакового пріоритету зліва направо.

Окремо перевіряємо, що калькулятор працює як із пробілами, так і без них, а також коректно приймає десятковий роздільник `,` або `.`.

Помилкові сценарії:
- `5 / 0` → повідомлення про ділення на нуль;
- порожній рядок → помилка;
- `5 +` → помилка про відсутній операнд;
- `5 ** 2` → помилка про некоректну послідовність;
- `hello` → повідомлення про невідомий символ;
- `2 3` → повідомлення про пропущений оператор;
- дуже велике число, що не вміщується в `decimal` → контрольована помилка без аварійного завершення програми.

## 6. Перевірка переходів між модулями

1. Відкрити завдання 1 → виконати → повернутися до меню.
2. Відкрити завдання 2 → виконати → повернутися до меню.
3. Відкрити гру → навмисно помилитися → повернутися до меню.
4. Відкрити калькулятор → обчислити приклад → повернутися до меню.
5. Обрати 0 → програма завершується.

Цей блок перевіряє саме наше додаткове меню, а не окремі алгоритми викладача.

## 7. Фінальна перевірка перед здачею

1. `dotnet restore`
2. `dotnet build`
3. `dotnet run`
4. пройти всі 4 модулі;
5. перевірити відображення українських символів;
6. перевірити запуск проєкту у Visual Studio 2022 17.8+;
7. зробити скриншот головного меню;
8. зробити щонайменше по одному скриншоту кожного завдання;
9. переконатися, що Git не містить `bin/`, `obj/`, `.vs/` та інших локальних артефактів;
10. перевірити, що GitHub-репозиторій доступний за посиланням.
