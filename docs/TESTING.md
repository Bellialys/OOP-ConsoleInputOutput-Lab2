# План тестування

## 1. Головне меню

| Ввід | Очікуваний результат |
|---|---|
| `1` | Відкривається завдання 1 |
| `2` | Відкривається завдання 2 |
| `3` | Відкривається завдання 3 |
| `4` | Відкривається завдання 4 |
| `0` | Програма коректно завершується |
| `9` | Повідомлення про помилку, повторний вибір |
| `abc` | Повідомлення про помилку, повторний вибір |
| порожній рядок | Повідомлення про помилку, повторний вибір |

## 2. Перевірка року на високосність

| Рік | Очікування | Причина |
|---:|---|---|
| 2024 | високосний | кратний 4, не кратний 100 |
| 2025 | не високосний | не кратний 4 |
| 1900 | не високосний | кратний 100, але не 400 |
| 2000 | високосний | кратний 400 |
| 2100 | не високосний | кратний 100, але не 400 |

Некоректне введення:
- `abc` → повторний запит;
- `0` → повторний запит;
- `-2024` → повторний запит.

## 3. Трикутник

### Висота 1
```text
1
```

### Висота 4
```text
      1
    2 2
  3 3 3
4 4 4 4
```

Перевірити:
- `0` → повторний запит;
- `-1` → повторний запит;
- `abc` → повторний запит;
- `21` → повторний запит;
- `20` → коректний вивід 20 рядків.

## 4. Мільйонер

Сценарії:
1. Перша відповідь неправильна → 0 балів і завершення гри.
2. Дві правильні, третя неправильна → 200 балів.
3. Усі 5 правильні → 500 балів.
4. `7` на питанні → повторний запит, рахунок не змінюється.
5. `abc` → повторний запит, рахунок не змінюється.

Окремо перевірити:
- рівно 5 питань;
- рівно 4 варіанти у кожного;
- одна правильна відповідь;
- після завершення гри програма повертається до меню.

## 5. Калькулятор

| Вираз | Очікування |
|---|---:|
| `5 + 5 * 10 + 4 / 2 - 3` | 54 |
| `2 + 3 * 4` | 14 |
| `20 / 5 + 3` | 7 |
| `10 - 2 * 3` | 4 |
| `8 / 2 * 2` | 8 |
| `20 - 5 - 3` | 12 |
| `1 + 2 + 3` | 6 |

Тести `8 / 2 * 2 = 8` і `20 - 5 - 3 = 12` окремо перевіряють виконання операцій однакового пріоритету зліва направо.

Помилкові сценарії:
- `5 / 0` → повідомлення про ділення на нуль;
- порожній рядок → помилка;
- `5 +` → помилка;
- `5 ** 2` → помилка;
- `hello` → помилка.

## 6. Фінальна перевірка

Перед здачею:

1. `dotnet restore`
2. `dotnet build`
3. `dotnet run`
4. пройти всі 4 модулі;
5. перевірити відображення українських символів;
6. перевірити повернення до головного меню;
7. перевірити запуск solution/project у Visual Studio 2022;
8. зробити скриншоти заставки, меню та кожного завдання;
9. переконатися, що Git не містить `bin/`, `obj/`, `.vs/` та інших локальних артефактів.
