# План тестування

## 1. Головне меню

| Ввід | Очікуваний результат |
|---|---|
| 1 | Відкривається завдання 1 |
| 2 | Відкривається завдання 2 |
| 3 | Відкривається завдання 3 |
| 4 | Відкривається завдання 4 |
| 0 | Програма завершується |
| 9 | Повідомлення про помилку, меню не закривається |
| abc | Повідомлення про помилку, меню не закривається |
| порожній рядок | Повідомлення про помилку |

## 2. Високосний рік

| Рік | Очікування | Причина |
|---:|---|---|
| 2024 | високосний | ділиться на 4, не на 100 |
| 2025 | не високосний | не ділиться на 4 |
| 1900 | не високосний | ділиться на 100, але не на 400 |
| 2000 | високосний | ділиться на 400 |
| 2100 | не високосний | столітній, не кратний 400 |

Додатково:
- `abc` → повторне введення;
- `0` або від’ємний рік → повідомлення про некоректне значення, якщо обрана вимога про додатні роки.

## 3. Трикутник

### Висота 1
```text
1
```

### Висота 4
```text
      1
    2 2
  3 3 3
4 4 4 4
```

Перевірити:
- висота 0;
- від’ємне число;
- текст;
- значення понад встановлену верхню межу.

## 4. Мільйонер

Сценарії:
1. Перша відповідь неправильна → 0 балів, гра завершується.
2. Дві правильні, третя неправильна → 200 балів.
3. Усі 5 правильні → 500 балів.
4. Ввід `7` на питанні → повторний запит без втрати гри.
5. Ввід `abc` → повторний запит.

Окремо перевірити, що кожне питання має саме 4 варіанти і правильна відповідь збігається з налаштованим індексом.

## 5. Калькулятор

| Вираз | Очікування |
|---|---:|
| `5 + 5 * 10 + 4 / 2 - 3` | 54 |
| `2 + 3 * 4` | 14 |
| `20 / 5 + 3` | 7 |
| `10 - 2 * 3` | 4 |
| `8 / 2 * 2` | 8 |
| `1 + 2 + 3` | 6 |

Помилкові сценарії:
- `5 / 0` → повідомлення про ділення на нуль;
- порожній рядок → помилка;
- `5 +` → помилка;
- `5 ** 2` → помилка;
- `hello` → помилка.

Якщо підтримуються десяткові числа, окремо перевірити формат десяткового роздільника відповідно до обраної культури.

## 6. Фінальна перевірка

Перед здачею:
1. `dotnet restore`
2. `dotnet build`
3. `dotnet run`
4. пройти всі 4 модулі;
5. перевірити українські символи;
6. перевірити повернення до меню;
7. зробити скриншоти заставки, меню та кожного завдання;
8. перевірити, що репозиторій не містить `bin/`, `obj/`, `.vs/` та інших тимчасових файлів.
