# Вихідне завдання

Цей файл фіксує вимоги викладача, щоб під час розробки проєкту ми не відхилилися від початкового завдання.

## 1. Перевірка року на високосність

Програма повинна:
- запитати у користувача рік;
- визначити, чи є цей рік високосним.

Правила:
1. кожен 4-й рік — високосний;
2. кожен 100-й рік — не високосний;
3. кожен 400-й рік — високосний.

## 2. Побудова трикутника

Програма повинна:
- запитати висоту трикутника;
- вивести числовий трикутник заданої висоти.

Приклад для висоти 4:

```text
   1
  2 2
 3 3 3
4 4 4 4
```

У рядку 1 число 1 виводиться один раз, у рядку 2 число 2 — два рази, і так далі.

## 3. Гра «Хто хоче стати мільйонером?»

Програма повинна:
- створити 5 питань;
- для кожного питання показувати 4 варіанти відповіді;
- дозволяти користувачу обрати один варіант;
- нараховувати бали за кожну правильну відповідь;
- незалежно від правильності відповіді переходити до наступного питання;
- після всіх 5 питань показувати підсумкову кількість балів.

У прикладі завдання використані питання:
- про кольори прапора України;
- про місто, у якому знаходиться ДТЕУ.

Для нашої реалізації ці два питання залишаємо та додаємо ще три власні.

## 4. Калькулятор

Користувач вводить арифметичний вираз одним рядком, наприклад:

```text
5 + 5 * 10 + 4 / 2 - 3
```

Очікуваний результат:

```text
54
```

Потрібно враховувати стандартний пріоритет операцій: множення і ділення виконуються раніше додавання і віднімання.

## 5. Матеріали для здачі

До виконаного завдання потрібно додати:
- скріншоти роботи програми;
- ZIP-архів проєкту **або** посилання на Git-репозиторій.

## 6. Додаткове оформлення нашого проєкту

Наступні елементи не змінюють алгоритмічні вимоги викладача, а лише об’єднують чотири завдання в один застосунок:

- стартова заставка;
- головне меню 1–4;
- пункт 0 для виходу;
- повернення до головного меню після завершення обраного завдання;
- перевірка некоректного введення;
- розділення коду на невеликі класи;
- власний алгоритм калькулятора без готового `eval`.

У нашій реалізації гра завжди проходить усі 5 питань. Неправильна відповідь дає 0 балів за конкретне питання, після чого програма переходить до наступного. Підсумковий рахунок показується після п’ятого питання.
