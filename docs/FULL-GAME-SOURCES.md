# Джерела питань повної гри

Повна 15-питальна версія використовує **адаптовані українською** питання з реальних випусків телевікторини «Кто хочет стать миллионером?».

Формулювання в програмі скорочені або перефразовані українською, але тема, варіанти та правильна відповідь збережені.
