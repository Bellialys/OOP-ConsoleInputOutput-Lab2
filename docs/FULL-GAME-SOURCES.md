# Джерела питань повної гри

Повна 15-питальна версія використовує українською мовою адаптовані формулювання за мотивами питань, які звучали у реальних випусках телевікторини «Кто хочет стать миллионером?».

Для підбору тем і правильних відповідей використані огляди реальних випусків на GameSHOWS.ru:

- випуск 19.02.2006;
- випуск 02.05.2009;
- випуск 29.10.2002;
- випуск 27.10.2018;
- випуск 27.05.2017;
- випуск 11.02.2017;
- випуск 04.11.2002;
- випуск 02.12.2017.

Формулювання в програмі адаптовані та перекладені українською, щоб не копіювати дослівно текст телевізійних питань і зберегти єдиний стиль інтерфейсу проєкту.

Повна гра має 15 питань зі зростанням складності. Як і в навчальному режимі цього проєкту, неправильна відповідь не перериває проходження: підсумковий результат показується після останнього питання.
