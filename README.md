# OOP Console Input/Output — Lab 2

Навчальний консольний проєкт на C# для дисципліни **«Об’єктно-орієнтоване програмування»**.

Проєкт об’єднує чотири завдання викладача в один застосунок із заставкою, головним меню, перевіркою введення та поверненням до меню після завершення кожного модуля.

## Завдання

1. **Перевірка року на високосність** — користувач вводить рік, а програма визначає, чи є він високосним за правилами 4 / 100 / 400.
2. **Побудова числового трикутника** — користувач задає висоту, а програма виводить відповідну кількість рядків.
3. **Гра «Хто хоче стати мільйонером?»** — 5 питань, по 4 варіанти відповіді, +100 балів за кожну послідовну правильну відповідь; перша неправильна відповідь завершує поточну гру.
4. **Калькулятор** — обчислення арифметичного виразу з операціями `+`, `-`, `*`, `/` із правильним пріоритетом множення та ділення.

Точні початкові вимоги винесені окремо: [Вихідне завдання](docs/ASSIGNMENT.md).

## Головна ідея

Застосунок має бути **простим для пояснення, але якісно структурованим**:

- один консольний проєкт;
- зрозумілий українськомовний інтерфейс;
- окремий модуль для кожного завдання;
- базові принципи ООП без надмірної архітектури;
- коректна обробка типових помилок введення;
- без сторонніх бібліотек;
- без готових обчислювачів виразів на кшталт `DataTable.Compute`;
- запуск із Visual Studio / VS Code та через `dotnet run`.

## Технологічна база

Планований `TargetFramework`: **net8.0**.

Його обрано насамперед для сумісності з Visual Studio 2022 (17.8 або новішою). Новіший встановлений .NET SDK також може збирати проєкт із нижчим цільовим фреймворком.
