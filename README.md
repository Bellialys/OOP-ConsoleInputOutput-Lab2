# OOP Console Input/Output — Lab 2

Навчальний консольний проєкт на C# для дисципліни **«Об’єктно-орієнтоване програмування»**.

Проєкт об’єднує чотири завдання викладача в один застосунок із заставкою, головним меню, перевіркою введення та поверненням до меню після завершення кожного модуля.

## Завдання

1. **Перевірка року на високосність** — правила 4 / 100 / 400.
2. **Побудова числового трикутника** — введення висоти та формування трикутника за допомогою вкладених циклів.
3. **Гра «Хто хоче стати мільйонером?»** — підменю з навчальною демо-версією на 5 питань та повною версією на 15 питань, адаптованих із реальних випусків шоу.
4. **Калькулятор** — власний розбір арифметичного виразу з операціями `+`, `-`, `*`, `/` та правильним пріоритетом операцій.

Початкову умову та подальші уточнення реалізації зафіксовано окремо: [Вихідне завдання та уточнення](docs/ASSIGNMENT.md).

## Калькулятор

Калькулятор не використовує `DataTable.Compute`, `eval` або аналогічні готові механізми.

Наприклад:

```text
5 + 5 * 10 + 4 / 2 - 3
```

Результат:

```text
54
```

Підтримуються:
- пріоритет `*` і `/` над `+` і `-`;
- виконання операцій однакового пріоритету зліва направо;
- вирази з пробілами та без пробілів;
- десяткові числа з `.` або `,`;
- перевірка порожнього виразу, невідомих символів, пропущених операндів/операторів та ділення на нуль.

Дужки, степені, математичні функції й унарні оператори не входять до вимог цієї роботи.

## Запуск

### Visual Studio 2022

1. Клонувати репозиторій.
2. Відкрити файл `OOP-ConsoleInputOutput-Lab2.sln`.
3. Запустити проєкт `OOPConsoleInputOutputLab2`.

### Командний рядок

```text
dotnet restore OOP-ConsoleInputOutput-Lab2.sln
dotnet build OOP-ConsoleInputOutput-Lab2.sln
dotnet run --project OOPConsoleInputOutputLab2.csproj
```
