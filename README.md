# OOP Console Input/Output — Lab 2

Навчальний консольний проєкт на C# для дисципліни **«Об’єктно-орієнтоване програмування»**.

Мета проєкту — об’єднати чотири окремі завдання в один акуратний консольний застосунок із заставкою, головним меню, перевіркою введення та поверненням до меню після виконання кожного модуля.

## Завдання

1. **Високосний рік** — визначення, чи є введений рік високосним за правилами 4 / 100 / 400.
2. **Трикутник** — побудова числового трикутника заданої користувачем висоти.
3. **«Хто хоче стати мільйонером?»** — 5 питань, 4 варіанти відповіді, нарахування балів за послідовні правильні відповіді та завершення гри після помилки.
4. **Калькулятор** — обчислення рядкового арифметичного виразу з операціями `+`, `-`, `*`, `/` з правильним пріоритетом множення та ділення.

## Концепція

Проєкт має бути:
- простим для пояснення на захисті;
- достатньо структурованим, щоб демонструвати базові принципи ООП;
- без сторонніх бібліотек;
- без прихованих готових обчислювачів на кшталт `DataTable.Compute`;
- з коректною обробкою помилкового введення;
- з українськомовним інтерфейсом;
- придатним для запуску через Visual Studio / VS Code та `dotnet run`.
